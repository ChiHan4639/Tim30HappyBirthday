# 把圖放這裡

一面兩個檔案，正反面共四個。載入器依序找 `.webp` → `.png` → `.jpg`。

| 檔名 | 內容 |
| --- | --- |
| `front.webp` | 正面的筆跡 |
| `front-gloss.webp` | 正面的局部上光遮罩 |
| `back.webp` | 背面的筆跡 |
| `back-gloss.webp` | 背面的局部上光遮罩 |

目前這組是從 1754 × 2480 的 PNG 轉的，4.8MB → 1.1MB：

```bash
cwebp -q 85 -alpha_q 100 -m 6 front.png -o front.webp
```

`-alpha_q 100` 讓 alpha 維持無損 —— 筆跡的形狀就在 alpha 裡，那個不能壓。

只放正面也可以，背面就是一張乾淨的空白卡。

## 筆跡

**去好背的透明 PNG。** 程式原封不動貼上去，不碰你的顏色，只做兩件事：

1. 裁掉四周全透明的空白（滿版稿除外，見下）
2. 依照留白設定把圖等比縮放置中到卡片上

`config.js` 的 `ink.density` 會對 alpha 做 gamma，預設 1.7 是加濃。
想完全照原檔就設 1.0。

## 局部上光

**白色 = 上光，黑色 = 不上光。** 透明 PNG 也可以，那就用 alpha 當遮罩
（有形狀的地方上光）。不透明的圖用亮度，並自動判斷極性 —— 白紙上的圖案
會取反，黑底白圖照用。中間調會得到部分強度的塗層。

實作上是 three.js 的 clearcoat：紙面維持霧面，只有遮罩指定的地方多一層
透明塗層。轉動卡片時那些區域會掃過一道反光，跟實際的 spot UV 一樣。

## 滿版稿（建議）

圖的長寬比跟卡片一致（A5 = 1:1.419，誤差 6% 以內）時，程式會當成
**已經排好版的滿版稿**：原樣鋪滿、不裁切、不重新置中，你的留白原樣保留。

這對上光很重要 —— 上光元素常常刻意放在筆跡的空白處，照筆跡的外框裁切
會把它們切掉。

非滿版的圖才會裁到筆跡邊界再置中，這時上光那張會套用**筆跡算出來的同一個
裁切框**，所以兩個檔案必須是同一份文件、同樣框法匯出的：

- ✅ 同一個畫布尺寸，兩層各自輸出
- ✅ 同樣框法但解析度不同（裁切框是用比例算的）
- ❌ 上光那張自己另外裁過 → 會錯位

## 尺寸

長邊 1600~2500 px 就很夠了（A5 卡面貼圖是 1128 × 1600 px，約 7.6 px/mm）。
目前這組是 1754 × 2480，也就是 A5 @300dpi。

HEIC 讀不了，先轉成 PNG 或 WebP。
